Scheduler — это веб-сервер для управления задачами (ToDo-листом).
Он хранит задачи в локальной базе данных SQLite, позволяет:
добавлять, редактировать, получать и удалять задачи;
отмечать задачи как выполненные;
работать с повторяющимися задачами (ежедневными, еженедельными и т.д.);
возвращать данные в формате JSON для фронтенд-клиента.

Реализованы все обработчики API:
POST /api/task — добавление новой задачи
GET /api/task — получение задачи по ID
PUT /api/task — редактирование задачи
DELETE /api/task — удаление задачи
GET /api/tasks — получение списка ближайших задач
POST /api/task/done — отметка задачи как выполненной
Настроена инициализация базы данных при первом запуске
Реализовано считывание переменных окружения:
TODO_PORT — порт, на котором запускается сервер
TODO_DBFILE — путь к файлу базы данных
Добавлена автоматическая генерация базы данных, если файла нет
Все тесты в папке tests/ проходят успешно

Инструкция по запуску локально
go mod tidy
Создайте файл .env или задайте переменные вручную:
export TODO_PORT=7540
export TODO_DBFILE=./scheduler.db
go run ./server

Инструкция по запуску тестов
go test ./tests -v
